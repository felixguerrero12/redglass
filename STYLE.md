# Style: simple technical English

This project uses simple technical English (ASD-STE100 style).

Source pattern: [SimpleEnglish](https://github.com/AminBlg/SimpleEnglish) / Hermes `simple-english` skill.

## Rules (short)

1. Keep instruction sentences at 20 words or fewer.
2. Keep descriptive sentences at 25 words or fewer.
3. Use one word for one idea in the whole file.
4. Use active voice.
5. Use these modals only: can, will, must.
6. Put the condition before the command.
7. One instruction per sentence.
8. Do not use semicolons.
9. Do not use "-ing" verb forms as the main verb.
10. Do not change code names, paths, or identifiers to "simplify" them.

## Apply to

- `SKILL.md`
- `guides/`
- `agents/`
- `README.md`
- new research notes

## Do not apply to

- Quoted Heuer text
- Mermaid node ids
- File paths and field names in schemas
